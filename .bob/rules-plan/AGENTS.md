# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Planning

When asked to plan a feature, write the plan as a Markdown file in `.plans/`. Name it with a zero-padded two-digit sequence number followed by a short kebab-case description (e.g. `.plans/08-my-feature.md`). Pick the next available number by checking what already exists in `.plans/`. Do not place plan files in the project root or anywhere else.
